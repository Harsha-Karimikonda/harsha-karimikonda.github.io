Selected Engineering Projects

High-throughput model serving engines, concurrent Go systems, and applied computer vision.

Flagship • Inference Control Plane

Mini-Inference-Engine

A production-inspired, fully observable LLM inference control plane engineered to tackle GPU memory fragmentation and maximize serving throughput.

  • Continuous Dynamic Batching merging prompt prefill and decode phases without iteration stalls.
  • Paged Logical KV-Cache allocator eliminating external memory fragmentation into discrete chunks.
  • Radix Prefix Hash Reuse indexing chained SHA-256 block hashes for instant state retrieval.
  • Hardware-aware dynamic autoscaler with model VRAM sizing and zero-downtime graceful worker draining.

ONNX Inference Platform

High-throughput distributed batch inference server built in Go leveraging the ONNX Runtime for ultra-low latency model serving across production environments.

  • Goroutine worker pools managing concurrent request dispatching with minimal lock contention.

  • Optimized execution pipeline serving computer vision and NLP models at scale.
